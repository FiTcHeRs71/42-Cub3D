Si si, carré + transparence = forme libre ! 🎨                                                         
                                         
  Le principe                                                                                            
   
  L'image fichier est toujours rectangulaire (carrée pour cub3D). Mais tu rends transparents les pixels  
  que tu ne veux pas afficher → ton ennemi peut avoir n'importe quelle silhouette.
                                                                                                         
  Image 64×64 (carré)        À l'écran (rendu)              
  ┌────────────┐                                                                                         
  │  ░░░██░░░  │              ░ = transparent (skip)
  │  ░██████░  │              █ = pixel ennemi                                                           
  │  ████████  │                                                                                         
  │  ██░██░██  │              → on ne voit que la silhouette                                             
  │  ░░████░░  │                                                                                         
  └────────────┘                                            
                                                                                                         
  Le piège XPM + minilibx                                                                                
   
  Le canal alpha de XPM marche mal avec mlx_xpm_file_to_image. La technique fiable : couleur magique     
  (chroma key).                                             
                                                                                                         
  Étapes concrètes                                                                                       
   
  1. Dans GIMP                                                                                           
  - Peins le fond en magenta pur : #FF00FF (couleur qu'on n'utilise jamais dans le sprite).
  - Dessine ton ennemi par dessus.                                                                       
  - Exporte en XPM.               
                                                                                                         
  2. Dans le code (au rendu du sprite)                      
                                                                                                         
  #define TRANSPARENT 0xFF00FF                              
                                                                                                         
  int color = get_pixel(sprite, tex_x, tex_y);                                                           
  if ((color & 0x00FFFFFF) != TRANSPARENT)  // ignore les pixels magenta                                 
      put_pixel(frame, screen_x, screen_y, color);                                                       
                                                                                                         
  Alternative plus propre : utilise noir pur #000000 comme couleur transparente si ton sprite n'a pas de 
  noir, ou réserve une couleur que tu n'utilises jamais.                                                 
                                                                                                         
  Résultat : ennemi avec n'importe quelle forme (humanoïde, pieuvre, fantôme…), même si l'image est      
  techniquement un carré.

  2. Le chroma key — nouveau fichier srcs/draw/draw_sprite.c
                                                                                                         
  C'est ici que le chroma key opère :                                                                    
                                                                                                         
  #include "../../includes/cub3d.h"                                                                      
                                                            
  #define MAGENTA 0xFF00FF                                                                               
   
  static int    get_tex_pixel(t_tex_img *tex, int x, int y)                                              
  {                                                         
        if (x < 0 || y < 0 || x >= tex->width || y >= tex->height)                                       
                return (MAGENTA);                           
        return (*(unsigned int *)(tex->addr + y * tex->size_line                                         
                        + x * (tex->bpp / 8)));
  }                                                                                                      
                                                            
  static void   put_screen_pixel(t_mlx *mlx, int x, int y, int win_x, int win_y, int color)              
  {                                                         
        char    *pixel;                                                                                  
        int             offset;                             

        if (x < 0 || y < 0 || x >= win_x || y >= win_y)                                                  
                return ;
        offset = (y * mlx->size_line) + (x * (mlx->bits_per_pixel / 8));                                 
        pixel = mlx->img_data + offset;                     
        *(unsigned int *)pixel = color;                                                                  
  }
                                                                                                         
  /* Dessine `tex` à (dst_x, dst_y) à l'écran, avec chroma key magenta */                                
  void  draw_sprite(t_data *data, t_tex_img *tex, int dst_x, int dst_y)
  {                                                                                                      
        int     x;                                          
        int     y;                                                                                       
        int     color;                                      
                                                                                                         
        y = 0;
        while (y < tex->height)                                                                          
        {                                                   
                x = 0;
                while (x < tex->width)
                {
                        color = get_tex_pixel(tex, x, y);
                        if ((color & 0x00FFFFFF) != MAGENTA)        /* ← chroma key ici */               
                                put_screen_pixel(data->mlx, dst_x + x, dst_y + y,                        
                                        data->window_x, data->window_y, color);                          
                        x++;                                                                             
                }                                                                                        
                y++;                                        
        }
  }
